One original fortune-cookie line for a software developer, written as UTF-8
to `entry.txt` in the grader's output directory by a stdlib-only Python script.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 -P -s main.py
```

The entrypoint creates its output directory if needed, never removes it, and
writes the same bytes on every run.
